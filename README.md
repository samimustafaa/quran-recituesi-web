## **Project description**

**Mus'haf** is a Quran reading website created by **Sami Mustafa**. Its Albanian interface pairs authentic Arabic text from **Quran.com** with an emerald and gold book, a slow opening animation that reveals Al-Fatihah, and smooth right-to-left page turns.

## **Features**

- **The complete Quran:** 604 Madani pages, 114 Surahs, and 6,236 verses.
- **Authentic Arabic:** preserved Quran.com Uthmani text, QCF V2 calligraphy, and source page layouts.
- **Albanian interface:** navigation, messages, Surah labels, and search with support for ë and ç.
- **Animated book opening:** reveals the first Quran page before entering the reader.
- **Smooth navigation:** touch swipes, keyboard controls, and fast animated jumps to a page, Surah, Juz, or bookmark.
- **Responsive reading:** desktop spreads and single-page mobile layouts.
- **Personal reading tools:** saved pages, reading position, night mode, and distraction-free mode.
- **Reduced-motion support:** adapts animations to the reader's preference.

## **Tech stack**

| **Technology** | **Purpose** |
| :--- | :--- |
| **HTML5 & CSS3** | Responsive interface, typography, and page styling |
| **JavaScript ES modules** | Reader controls, navigation, and application state |
| **Three.js / WebGL** | Book scene, cover opening, lighting, and pointer movement |
| **Canvas 2D & SVG** | First-page texture and original book artwork |
| **Quran.com API v4 & QCF V2 fonts** | Imported Quran text, word glyphs, page positions, and calligraphy |
| **JSON & localStorage** | Page data, bookmarks, preferences, and saved reading position |
| **Python & Node.js** | Data import and content verification scripts |
